## 写了什么

- **计算机基础**：计算机网络原理、计算机组成原理、数据库系统概述，想把系统怎么跑起来从底层捋一遍。
- **AI 与 Agent**：从模型的输入输出讲到工具选择，再讲到 Coding Agent 的工作方式。
- **工程工具链**：git 和 npm 的核心概念与常用命令，写给自己随时查的版本。
- **前端**：`语言基础`、`页面构建`、`浏览器 API`、`Vue`、`网络与数据`、`工程化`、`测试与质量`

## 从哪读起

- 想先看一篇：[Agent 基础](https://throne24.github.io/Node-One/posts/AI.html)，信息密度较高。
- 想补计算机基础：按 [计算机组成原理](https://throne24.github.io/Node-One/posts/jizu.html) → [计算机网络原理](https://throne24.github.io/Node-One/posts/jiwang.html) → [数据库系统概述](https://throne24.github.io/Node-One/posts/shujuku.html) 的顺序读。
- 想马上用得上：先看 [git](https://throne24.github.io/Node-One/posts/git.html) 和 [npm](https://throne24.github.io/Node-One/posts/npm.html)。

## 关于这个仓库

文章都是 Markdown，放在 `posts/` 目录，由 VitePress 渲染成站点，推送到 `main` 后自动发布到 GitHub Pages。想在本机看效果，`npm install` 之后跑 `npm run dev`。
